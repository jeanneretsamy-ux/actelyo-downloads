Le même écosystème, sur votre infrastructure

Installateurs Windows : les cartes Applications livrent des EXE ou ZIP. Les modèles GGUF restent séparés et se chargent dans Actelyo LLM.

Kit portable : un petit ZIP contient le catalogue et un script de téléchargement qui vérifie les empreintes. Les poids et les gros paquets sont récupérés dans le dossier choisi, pour pouvoir préparer un autre ordinateur.

Docker : le kit de services prépare le moteur local, les embeddings et Actelyo RAG. Les applications graphiques Windows s’installent avec leurs EXE.

Télécharger le kit Dockerdocker compose up --build -d

Copiez d’abord vos GGUF dans le dossier models et renseignez les chemins du fichier .env fourni. Le kit peut demander plusieurs Go de disque. Les images ne sont pas téléchargées par l’ERP.

Les liens, versions, tailles et empreintes proviennent du catalogue Actelyo. Un modèle installé n’est pas nécessairement chargé. Les installateurs non signés peuvent déclencher l’avertissement habituel de Windows. Vos corpus privés ne sont pas inclus.
